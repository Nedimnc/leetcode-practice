# LeetCode Practice

Daily practice log, organized by pattern instead of by date, so it stays
useful as a review tool later (not just a pile of solved problems).

## How I'm using this repo
- One file per problem, saved in the folder for the pattern it teaches.
- Each file has the problem link, my approach, and time/space complexity.
- I update the table below after every problem — it's my quick-scan index
  for interview prep later.
- Order I'm working through patterns: arrays/hashing → two pointers →
  sliding window → stacks/queues → linked lists → binary search → trees →
  graphs → dp.

## Workflow per problem
1. Try for ~20-25 min without help.
2. If stuck, look at the solution, understand *why* it works.
3. Write it up in my own words (approach + complexity).
4. A day or two later, redo the same problem from scratch, no notes.
5. Update the table above.
